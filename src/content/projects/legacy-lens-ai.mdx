## What it does

LegacyLens AI ingests legacy codebases and uses Azure OpenAI GPT-4o to extract
plain-English business intent. It turns that analysis into a risk-ranked
modernization roadmap, then produces refactored code with test scaffolds.

The project keeps the analysis and proposed changes connected. Its output
includes intent maps, phased recommendations, and side-by-side refactoring views
so a reviewer can inspect the proposed migration instead of receiving only
generated code.
